# MiniDB

Учебная СУБД на Java для предметной области «Автосалон». Внешние библиотеки и JDBC не используются.

## Возможности

- Таблицы с первичными и внешними ключами.
- Типы `INT`, `DOUBLE`, `STRING`, `DATE`, `BOOLEAN`.
- Команды `CREATE TABLE`, `DROP TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`, `CREATE INDEX`.
- Условия `WHERE` с операторами `=`, `!=`, `<>`, `<`, `<=`, `>`, `>=`.
- Индексы на основе `TreeMap` для поиска по равенству и диапазону.
- Сохранение после каждой изменяющей команды, контроль целостности SHA-256 и восстановление из двух поколений снимков.

## Сборка и запуск

Требуется JDK 8 или новее.

Linux/macOS:

```sh
sh build.sh
```

Windows:

```bat
build.bat
```

Выполнение демонстрации на новой базе:

```sh
java -jar dist/minidb.jar data examples/demo.sql
```

Интерактивная работа с сохранённой базой:

```sh
java -jar dist/minidb.jar data
```

По умолчанию данные хранятся в каталоге `data`. Команды завершаются `;`. `HELP;` выводит справку, `EXIT;` завершает работу. SQL-файлы используют UTF-8. Повторная демонстрация требует нового каталога данных, поскольку создаёт таблицы.

## Проверки

После сборки:

```sh
java -cp out ru.lab.minidb.IntegrationTest
java -Xms256m -Xmx1g -cp out ru.lab.minidb.Benchmark
```

Интеграционные тесты проверяют операции с данными, типы, ограничения ключей, индексы, сохранение, восстановление и ошибки записи. Бенчмарк сравнивает поиск с индексом и полным перебором на 10 000, 50 000 и 100 000 строках.

## Структура

- `src/main/java/ru/lab/minidb` — модель, SQL-парсер, движок, файловое хранилище и консоль.
- `src/test/java/ru/lab/minidb` — интеграционные тесты и бенчмарк.
- `examples/demo.sql` — демонстрация работы с таблицами владельцев и автомобилей.
- `dist/minidb.jar` — собранное приложение.

## Ограничения

Поддерживается один предикат в `WHERE`. Составные ключи, `JOIN`, `AND/OR`, `ORDER BY` и транзакции из нескольких команд не реализованы. Изменяющая команда выполняется атомарно и сохраняет полный снимок базы. Одновременно с каталогом базы работает один экземпляр приложения.
